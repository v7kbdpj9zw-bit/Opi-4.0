# Opi-4.0Build a responsive web application called OPI 4.0.

OPI stands for Physics Research Assistant.

Target device: iPad Air.
Platform: Web application, optimized for Safari.

Design:
- Dark scientific interface
- Black/navy background
- Cyan and violet accents
- Minimal, sophisticated research laboratory aesthetic

Main sections:
1. AI Research Chat
2. Equation Laboratory
3. Experiment Dashboard
4. Research Notebook
5. Settings

Requirements:
- Responsive iPad layout
- Korean language interface
- Mathematical equation rendering
- Graph visualization
- Persistent research notes
- Online AI integration prepared through a secure backend
- Never expose API keys in frontend code

Create a functional first version.
Do not use placeholder buttons for core navigation.
